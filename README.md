# Kuppio legal pages

Terms of Service and Privacy Policy for the Kuppio app, published with GitHub Pages:

- https://alan-6565.github.io/kuppio-legal/terms
- https://alan-6565.github.io/kuppio-legal/privacy

Shop pages for the app's share links and QR codes (Hidden-Gem #117):

- `s/?id=<shop id>`: the shop with an "Open in Kuppio" button
- `qr/?id=<shop id>`: a printable QR poster for the counter or market table

Both read published shops through Supabase's public (publishable) key, the same one
the app ships with; row-level security only returns published, live shops.
